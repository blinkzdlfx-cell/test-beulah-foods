# Beulah Foods Email Templates

HTML email templates for authentication and marketing.

Authentication:
- authentication/confirm-email.html
- authentication/reset-password.html

Marketing:
- marketing/welcome.html
- marketing/promotion.html
- marketing/new-product.html
- marketing/announcement.html
- marketing/abandoned-cart.html
- marketing/re-engagement.html

Authentication templates are intended for Supabase Auth. Marketing templates use clearly marked placeholders that should be replaced with the merge-tag syntax of the email provider.
